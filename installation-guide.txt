RESONANCE · PRISM 2.2.5 内测版

这是 Windows 正式安装程序，包含全部本地模型。可通过分卷安装文件或原始完整 ZIP 分发。

分卷发布（如 GitHub Releases）：
下载 RESONANCE-2.2.5-Offline.exe 和 RESONANCE-2.2.5-Offline-1.bin 至 RESONANCE-2.2.5-Offline-15.bin，全放在同一个文件夹，保留原文件名。
从同一次发布下载 SHA256SUMS.txt，逐个校验 EXE 与全部 15 个 BIN。不能只下载 EXE，不要混用不同日期的分卷。
GitHub 自动生成的 Source code (zip) / Source code (tar.gz) 是发布仓库源码，不是软件安装包。
如果下载的是原始「RESONANCE-2.2.5-完整安装包.zip」，先完整解压。该 ZIP 的 SHA-256 只适用于 ZIP 本身，不适用于任何分卷。

安装：
1. 下载齐分卷文件；若下载的是完整 ZIP，则先完整解压。安装 EXE 和全部 15 个 BIN 分卷必须留在同一个文件夹。
2. 运行 RESONANCE-2.2.5-Offline.exe，不要直接在压缩包中运行。
3. 在向导中选择：
   最新版本（推荐） — 31.11 GB：全部功能、全部本地模型，不影响使用；不安装历史程序。
   全版本 — 32.78 GB：全部功能与模型，额外提供 14 个历史归档，共 15 个版本条目，可在主窗口切换。
   大小按十进制GB，含模型与当前版本首次展开；已有相同模型复用。下载包大小不随选项改变。
4. 安装后从开始菜单打开 RESONANCE，无需另外启动 Python 或模型终端。
5. 到「设置 → 关于共振 → 我的内测码」复制并独立备份自己的完整内测码。
6. 「设置 → 外观」可启用「内测 · 极光星轨」；歌词字体可选「内测专属 · 星笺手写」，正式歌词、CC与小窗统一应用。

当前内测版首次启动自动领码。后续正式版停止发放新码，保留已有码导入；不绑定电脑或软件版本，没有到期日。换电脑、重装系统、清理数据前请先备份。纯离线不能阻止转发或借旧内测包补领。

内含9类模型、11种配置和必要本地推理运行文件。模型按需加载，不会同时常驻显存。旧版保留各自当时功能。
