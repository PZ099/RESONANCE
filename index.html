07 / GOOD QUESTIONS

开始前，
你可能想知道。

共振是一个音乐播放器吗？+

共振主要读取、分析正在播放的声音，并展示频谱、歌词和歌曲信息。你可以继续使用原来的音乐软件或浏览器。播放、暂停和切歌等控制取决于音频来源是否支持；不支持的控制会禁用。

没有网络，还能用吗？+

本机模型、音频监听、频谱、录制以及已有的本地歌词和识别缓存可以离线使用。查询新的在线歌词、歌曲资料或使用可选在线指纹服务，需要网络。本地识曲的覆盖范围取决于已经导入的参考曲库与缓存。

任何视频、演唱会都能找到准确歌词吗？+

软件会结合可用的标题、歌手信息与音频识别尝试寻找歌词，但无法保证所有歌曲和录音版本都能匹配。现场演唱、混音、对白和强伴奏会增加难度。没有可靠歌词时，本机字幕可继续显示；复杂演唱的转录仍可能出错。

必须要 NVIDIA 显卡吗？+

支持的 GPU 可以加速部分本机推理，也提供 CPU 回退。不同模型对内存、显存和处理器的要求不同，CPU 模式可能明显更慢。目前尚未完成所有硬件组合的最低配置验证。建议使用 Windows 11 x64，并按电脑性能选择模型。

能在 Windows 10 上安装吗？+

安装范围包含 Windows 10 2004 及以上的 x64 系统，但这不代表全部功能已在所有版本完成适配。按应用捕获音频需要系统构建号 20348 或更新；较旧系统可尝试系统音频捕获。推荐 Windows 11 x64。

为什么安装器 71.7 MB，安装还要下载 28 GB？+

小型安装器负责下载与校验，首次完整安装数据约 28.24 GB，全部功能和本机模型均保留。它不是完整离线安装包。最新版本与全版本在下载后的原安装向导中选择，已有正确模型可由该向导复用。需要离线安装时，可使用下方高级说明中的 EXE 与全部 15 个 BIN；GitHub 的 Source code 不是安装包。神经网络推理在本机运行，不要求购买云端 AI API；在线服务的使用条件以服务方为准。

内测代码和专属外观，之后还能用吗？+

当前内测版提供内测代码，用于后续版本导入内测资格及相关专属外观。请在软件中备份代码，并在升级或更换电脑时妥善保管。星轨背景与手写风歌词属于内测专属体验。
