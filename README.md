## 使用范围

推荐 Windows 11 x64。按应用捕获需要 build 20348 或更新；部分受保护或绕过系统混音的音频仍可能无法捕获。播放、切歌和进度功能取决于来源支持情况。

没有标题的音源也会尝试音频识别，但不能保证所有歌曲、演唱会和录音版本都可匹配。参考曲库、歌词来源覆盖、噪声和伴奏都会影响结果；复杂演唱的字幕仍可能出错。
